موقع إيـف — دليل التعديل والنشر على GitHub Pages
===============================================

الملفات:
- index.html          هيكل الصفحة والأقسام.
- style.css           الألوان والتصميم المتجاوب.
- data.js             المكان الأساسي لتعديل الأسماء والوصف والعناصر والروابط.
- script.js           عرض البطاقات ومؤثر صوت النقر.
- assets/eef-avatar.png صورة إيـف التي أرسلتها.

طريقة النشر على GitHub Pages:
1) سجّل الدخول إلى GitHub وأنشئ مستودعًا جديدًا (Repository).
2) ارفع كل الملفات والمجلدات الموجودة داخل هذا المجلد إلى جذر المستودع، وليس ملف ZIP نفسه.
3) افتح Settings داخل المستودع.
4) اختر Pages من القائمة.
5) من Build and deployment اختر Deploy from a branch.
6) اختر الفرع main والمجلد /(root)، ثم اضغط Save.
7) انتظر قليلًا وسيظهر رابط موقعك في صفحة Pages.

طريقة تعديل الموقع:
1) من مستودع GitHub افتح data.js ثم اضغط رمز القلم Edit.
2) غيّر name للاسم، وdescription للوصف.
3) عدّل عناصر files وapps وediting وaddons.
4) كل عنصر يكتب بهذا الشكل:
   { name: "اسم العنصر", description: "وصف مختصر", icon: "✦",
     image: "assets/icon.png", url: "files/my-file.zip", label: "ملف" }

- name: اسم البطاقة.
- description: الوصف الذي يظهر تحت الاسم.
- icon: رمز احتياطي يظهر إذا لم تضف صورة.
- image: مسار صورة الأيقونة. ارفع الصورة إلى assets ثم اكتب مسارها هنا.
- url: رابط الموقع أو رابط الملف. للملفات ارفعها إلى مجلد files ثم اكتب مسارها مثل files/my-file.zip.
- label: وصف تنظيمي اختياري.

5) اضغط Commit changes لحفظ التعديل. سيُحدّث GitHub Pages الموقع تلقائيًا بعد دقائق.

تغيير الصورة الشخصية:
- استبدل assets/eef-avatar.png بالصورة الجديدة مع الإبقاء على الاسم نفسه، أو عدّل مسار الصورة في index.html.

إضافة قسم جديد:
- أضف section في index.html مع عنصر div له id جديد.
- أضف مصفوفة جديدة في data.js.
- استدعِ renderItems في آخر script.js للقسم الجديد.
إذا كنت تريد فقط تغيير أسماء الأقسام الحالية، عدّل عناوين h2 في index.html.

ملاحظات:
- صوت النقر يُنشأ داخل المتصفح ولا يحتاج ملف صوت. بعض المتصفحات لا تسمح بالصوت إلا بعد أول لمسة من المستخدم.
- الموقع ثابت Static، لذلك التعديل يتم من ملفات GitHub كما طلبت؛ لا توجد لوحة تحكم داخل الموقع نفسه.
- لا تضع كلمات مرور أو مفاتيح سرية في ملفات الموقع العامة.
